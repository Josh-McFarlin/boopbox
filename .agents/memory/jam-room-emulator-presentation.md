---
name: Jam-room emulator presentation
description: The visual scope of the browser emulator when embedded in a jam room.
---

The emulator embedded in a jam room should show only the FM-1 emulator and the controls needed to use it. Do not include the standalone emulator page's site navigation, title, introduction, help text, or download controls.

**Why:** The user explicitly corrected the room embed to show the emulator, not the rest of the page that contains it.

**How to apply:** Keep the room-specific embed compact while preserving the device panel and its power-on interaction; this does not change the standalone emulator page.
