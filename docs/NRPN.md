# BoopBox: the NRPN map

You can set each parameter of a track over MIDI with an **NRPN**. This includes the parameters of the sound,
the mix and the sequencer. This map uses the same layout as the NRPN map of JIANT FM. An NRPN gives more
resolution than a CC. The CC map (CC5 7 10 71..75 91 93 94, CC11, CC64) and MIDI LEARN do not change.

## Send an NRPN

To set a parameter, send these messages on the MIDI channel of the track:

1. Send CC99 (NRPN MSB) with the value **0**.
2. Send CC98 (NRPN LSB) with the number of the parameter. The tables below give the numbers.
3. Send CC6 (data entry MSB) with the high 7 bits of the value.
4. Send CC38 (data entry LSB) with the low 7 bits of the value.

Note: If you set MIDI 3 > IN = CH n, the messages on channel n go to the selected track.

## How the BoopBox uses the value

- The value has 14 bits (0..16383). The BoopBox scales the value over the range of the parameter:
  `v = min + (x * (max - min) + 8191) / 16383`.
- If you send only CC6, the value has 7 bits (`x = msb * 129`).
- The parameter stays selected. Each new CC6 / CC38 sets the same parameter again.
- CC99 with a different value ends the selection. An RPN (CC101 / CC100) also ends the selection.
- At power-on, no parameter is selected.
- On a **drum track**, LVL, REV and DLY use the drum mix ranges of that track. The other numbers set the
  same values as on a synth track.
